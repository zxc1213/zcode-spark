# ZCode Spark

<p align="center"><img src="docs/icon.png" width="88" alt="ZCode Spark"></p>

**ZCode 桌面版提示词工作台**：在输入框旁放一颗星芒，把你的草稿改写成更清晰、更可执行的提示词再发出去。

零第三方依赖、零构建、不改 ZCode 安装目录、不碰签名。

```
写得潦草 → 点 ✨ → 选一个动作 → 模型改写 → 回填输入框 → 你检查 → 发送
                                ↘ 不满意一键撤销（可连撤多步），原文永不丢
```

灵感来自社区项目 [ZCode+](https://github.com/Llliao1113/zcode-plus)（同为 CDP 注入方案），但定位不同：ZCode+ 是一颗按钮 + 三种增强模式；**Spark 是一个多动作工作台**，并补了几处让日常使用更稳的细节。

## 和 ZCode+ 的差别

| | ZCode+ | ZCode Spark |
| --- | --- | --- |
| 动作 | 单一增强（三套模板） | 5 个独立动作：增强 / 精简 / 结构化 / 中译英 / 纠错 |
| 触发 | 点击按钮 | 按钮菜单 + 快捷键 `Ctrl+Shift+E`（可关） |
| 撤销 | 单步 | 多步撤销栈（最多 20 步） |
| 草稿冲突 | 保留结果不覆盖 | 检测到草稿已改动时不回填，改为复制到剪贴板并提示 |
| 配置存放 | 连接参数在页面 localStorage | 统一在控制器配置文件，页面只拿副本；API Key 不进页面 |
| 诊断 | 最近 8 次记录 | 记录 + `--doctor` 命令行体检 + `--attach` 附着已有调试端口 |
| 自定义模板 | 支持 | 不支持（动作固定，行为可预期，失败更好归因） |

## 环境要求

- Windows（ZCode 桌面版 3.x）
- Node.js **22+**（用到原生 WebSocket / fetch；安装器会把当前 node 路径写进启动器）

> macOS / Linux 暂不支持，代码里的平台层预留了位置但没有做实机验证。

## 安装

```bat
git clone <本仓库地址>
cd zcode-spark
node install.mjs
```

安装器会：

1. 复制程序到 `%LOCALAPPDATA%\ZCodeSpark`（`--dest <目录>` 可改）
2. 生成星芒图标与无窗口启动器 `launcher.vbs`
3. 首次安装写入 `zcode-spark-config.json`，并自动探测 `ZCode.exe`
4. 在桌面创建「ZCode Spark」快捷方式（`--no-shortcut` 可跳过）

重复运行 = 覆盖程序文件，**保留已有配置**。

源码目录也能直接跑：`node controller.mjs`（前台可见日志）。

## 使用

1. 双击桌面「ZCode Spark」。若原版 ZCode 正在运行，会弹窗询问是否关闭重启（会先确认，未发送的草稿请自行保留）。
2. 等 2-3 秒，输入框左下角模式切换右侧出现 ✨。
3. 写草稿 → 点 ✨ → 选动作 → 等待回填（最长 95 秒，处理中再点一次可取消）。
4. 回填后点旁边的撤销箭头可回退，连续改写过可以连撤。
5. **右键 ✨** 或菜单里的「设置」打开设置面板。

快捷键：`Ctrl+Shift+E` 直接触发「默认动作」，可在设置里关闭。

### 五个动作

| 动作 | 做什么 |
| --- | --- |
| 增强 | 补全目标、范围、约束与期望产出，保留原意与语言 |
| 精简 | 去掉重复与空话，保留全部硬约束，约原文六成以内 |
| 结构化 | 整理成 目标 / 现状 / 约束 / 交付物 / 验收 / 待确认 的规格 |
| 中译英 | 转成地道英文提示词，代码、路径、报错原文逐字保留 |
| 纠错 | 只改错别字、标点、语病，最小改动 |

所有动作共用一条输出纪律：只输出改写后的提示词、不回答问题、不改动代码块与报错原文。

## 配置

安装目录下的 `zcode-spark-config.json`（首次运行自动生成，带 `_readme` 说明）：

| 字段 | 说明 |
| --- | --- |
| `zcodePath` | `ZCode.exe` 完整路径；留空自动探测。环境变量 `ZCODE_SPARK_ZCODE_PATH` 优先级最高 |
| `port` | 调试端口，默认 9337，占用时自动顺延 9337-9361 |
| `hotkey` / `hotkeyEnabled` | 快捷键（默认 `Ctrl+Shift+E`）与开关 |
| `defaultAction` | 快捷键触发的动作 |
| `llm.mode` | `auto`（复用 ZCode 供应商）或 `manual`（直连任意兼容服务） |
| `llm.providerId` / `llm.model` | 自动模式下指定供应商与模型；留空 = 跟随输入框当前模型，再兜底到第一个启用的供应商 |
| `llm.baseUrl` / `llm.protocol` | 手动模式的地址与协议：`anthropic`、`chat`、`responses` |
| `llm.apiKey` | 手动模式的 Key（只存在这个文件里，不会返回页面、不会写日志） |
| `llm.allowLocal` | 允许请求 127.0.0.1 等本机/内网地址（本机代理场景，默认开） |

配置也可以完全在设置面板里改；面板写入走控制器，Key 只进不出（留空表示不修改，勾「清除」才清空）。

### 关于「自动模式」

自动模式读 `~/.zcode/v2/config.json`（以及工作区级 `.zcode/v2/config.json`）里**已启用**的供应商，按输入框显示的模型标签（形如 `供应商/模型`）匹配，匹配不到就用第一个带 Key 的启用供应商。

实测注意：ZCode 存的 Key 不一定是可直接直连的开放平台 Key。若自动模式返回 **HTTP 401**，说明这个 Key 只能由 ZCode 自己的网关使用，请改用**手动连接**，填一个大模型开放平台的普通 API Key（bigmodel / z.ai / OpenRouter / DeepSeek 等均可）。

```bat
node controller.mjs --doctor
```

会打印 ZCode 路径、端口占用、供应商清单、自动解析结果与最终端点，排错先看它。

## 运行原理

```
「ZCode Spark」快捷方式（wscript 无窗口启动 launcher.vbs）
  └→ 控制器（常驻 Node 进程，单实例锁，配置与 Key 只在这里）
       ├─ 分配空闲调试端口，用 --remote-debugging-port 拉起 ZCode.exe
       ├─ CDP 附着所有 page target，注入 inject.js（新窗口/刷新自动重注入）
       ├─ 页面经 Runtime binding 把草稿发给控制器 → 控制器调用模型
       ├─ 页面回填：控制器先发受信全选键（Ctrl+A），再 Input.insertText
       └─ 草稿在请求期间被改动 → 不回填，结果进剪贴板
```

关键取舍：

- **原版 ZCode 零影响**：不改安装目录、不改文件、不破坏签名；想用原版直接点原版快捷方式
- **富文本编辑器只认受信输入**：ZCode 3.11+ 的 Lexical 输入框会丢弃程序化选区与合成事件，所以回填必须走 CDP 的真实按键 + 真实插入；页面侧保留粘贴与 execCommand 两条降级通道
- **回填前校验**：写前比对草稿是否还是发起时那份，写后按「行内容」比对是否被完整接受（富文本会把连续换行拆成 block + `<br>`，空行数天然有出入，因此不做逐字节比对）
- **凭据不落页面**：面板只拿到 `apiKeySet: true/false`

## 排错

| 现象 | 处理 |
| --- | --- |
| 提示未找到 ZCode | 在配置里填 `zcodePath`，或设环境变量 `ZCODE_SPARK_ZCODE_PATH` |
| 按钮不出现 | 确认是从「ZCode Spark」入口启动的（原版启动没有调试端口）；等 2-3 秒 |
| 自动模式 401 | 改用「手动连接」，填开放平台的 API Key（见上文） |
| 自动模式 404 | Base URL 与协议不匹配，切 `anthropic` / `chat` / `responses` 再试 |
| 改写很慢或超时 | 默认 95 秒上限；换更快的模型，或在设置里换供应商 |
| 提示输入框没有接受结果 | 该版本编辑器结构可能变了，看 `zcode-spark.log`，并检查 `inject.js` 里的 `data-testid` 选择器 |
| 想看着日志跑 | 安装目录执行 `node controller.mjs`（前台输出 + `zcode-spark.log`） |
| 端口冲突 | 自动顺延；全占用就改配置里的 `port` |

端到端测试用一个复刻 composer 结构的静态页替代真实 ZCode，不需要启动或重启你的 ZCode。

## 隐私

- 增强请求只包含当前草稿文本，不带会话历史、附件或代码库内容
- 调试端口只监听 127.0.0.1
- 无遥测、无网络上报；日志不记录草稿与 Key（错误信息自动脱敏）
- 手动模式的 API Key 明文存在你自己的 `zcode-spark-config.json` 里，注意别提交到仓库
